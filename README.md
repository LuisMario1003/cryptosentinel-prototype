# CryptoSentinel — prototipo (React + Tailwind + Lucide)
    npm install
    npm run dev
Estado local con datos simulados en `src/data/mock.js` (UUID + llaves foráneas según el Modelo de Datos).
Toda la lógica de datos vive en `src/store.jsx`; al conectar el backend se reemplazan sus acciones por llamadas a la API.
